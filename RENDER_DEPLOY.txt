MUAMMOLAR VA YECHIMLAR
═══════════════════════════════════════════════════════════

❌ Build Failed: "failed to build Dockerfile"
   → Logs'da xatoni o'qing
   → go.mod, go.sum, Dockerfile mavjudligini tekshiring
   → GitHub'da barcha fayllar bor ekanini ko'ring

❌ "BOT_TOKEN topilmadi"
   → Environment Variables to'g'ri kiritilganini tekshiring
   → Manual Deploy qiling: Dashboard → Manual Deploy

❌ "PostgreSQL xato"
   → DATABASE_URL to'g'ri ekanini tekshiring
   → Railway Postgres running ekanini ko'ring
   → URL'da maxsus belgilar bo'lsa, escape qiling

❌ "Service Unavailable after 15 minutes"
   → Bu NORMAL! Render bepul plan uxlaydi
   → Birinchi request 30-50 soniya oladi
   → Keyin tez ishlaydi

❌ WebApp ochmayapti
   → webapp/env.js URL to'g'ri ekanini tekshiring
   → Netlify deploy bo'lganini tekshiring
   → Browser F12 → Console → xatolarni ko'ring
